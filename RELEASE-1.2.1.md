# Socket 1.2.1 — мини-апдейт

Небольшое обновление визуальных эффектов и доставки новых версий клиента.

- Новая анимация открытия меню: мягкая вспышка и свечение.
- Точки вокруг курсора в ClickGUI реагируют на движение мыши.
- **Glass Hands** — прозрачные руки и предметы с размытием, светлой кромкой и бегущим бликом.
- **Shader Hands** — два стиля переливающегося эффекта рук, настройка цвета, яркости и искажения.
- **Totem Ghost** — поднимающийся призрак после срабатывания тотема; есть предпросмотр.
- **Scan World** — световая волна по поверхностям мира, по таймеру, при тотеме и убийстве.
- **Lock Slot** — защита выбранных слотов, мечей, булавы и шалкеров от случайного выброса.
- Лоадер проверяет обновления клиента при открытии и перед запуском игры. Новые версии ядра скачиваются автоматически; сохраняется резервная копия предыдущего ядра.

**Скачать и играть:** скачайте **Socket loader.exe**, запустите и нажмите кнопку игры. Minecraft 1.21.4, Java 21, Fabric и необходимые моды устанавливаются автоматически.

Лоадер 1.2.1 поддерживает обновления через служебный файл `socket-update.zip`. Игрокам его скачивать и распаковывать не нужно. После установки этого лоадера следующие обновления клиента на Minecraft 1.21.4 будут приходить без замены EXE. В настройках должна быть включена опция «Автообновление ядра»; для новой установки она включена по умолчанию. Изменение самого лоадера или версии Minecraft может потребовать нового EXE.

Svetoch и Fog Blur в это обновление не включены.
