# Перенос модулей в Socket (Fabric 1.21.4)

Исходники из Telegram Desktop используют другой API `client.*`. В Socket добавлены адаптированные реализации на `socket.*`; исходные файлы в Downloads не изменялись.

- AuctionHelper: минимальная общая/поштучная цена, подсказка цены за штуку, прочность, фильтры зелий/кирки/булавы и зачарований. Подсветка по умолчанию статическая. Цена добавляется только в tooltip, а не в NBT/lore предмета. Фильтры зачарований задаются через `protection=5,unbreaking=5,mending=1`; исключения — аналогично. Неизвестные или некорректные правила не пропускают предмет.
- AutoResell: цикл `/ah` → эндер-сундук → хранилище → часы, интервал, ожидание ответа, обработка задержки и тайм-аут. Не повторяет нажатие часов без подтверждения, не начинает цикл поверх открытого меню и не нажимает слот с предметом на курсоре. Зависит от названий и структуры аукциона конкретного сервера.
- Saturation, Bloom: собственный GLSL вместо отсутствующих ресурсов и нестабильной рефлексии исходников. Выбор обработки мира до рук или после рук; HUD не обрабатывается.
- SkyShader: пять процедурных режимов и палитры неона. Шейдеры созданы заново, поэтому картинка не является точной копией исходного клиента. Небо Overworld; ванильные солнце/луна остаются.
- CustomFog: цвет, дистанция, сохранение подводного тумана.
- FakePlayer: только локальная копия игрока. Отрицательный свободный ID, очистка при отключении/смене мира, защита от удаления чужой сущности.
- ChunkAnimator: четыре направления и четыре функции сглаживания, очистка по дистанции и смене мира. Хук ванильного рендера чанков; альтернативные рендереры отдельно не проверялись.
- Motion Blur: существующий модуль переработан без дубля, история кадра инициализируется текущим изображением; HUD и ClickGUI не попадают в смаз. История сбрасывается при меню, смене мира и размера окна.

Исправления интерфейса: ник берётся из профиля игрока (вне мира — из сессии); offscreen-размытие использует viewport каждого буфера; во время проходов отключены depth/scissor/blending; после проходов восстанавливаются состояние и framebuffer. HUD и ClickGUI рисуются без записи в depth buffer.

Проверки:
- Полная Gradle-сборка с remapJar.
- tools/validate-effects.ps1: 13 сценариев разбора цен и OpenGL-проверки на AMD Radeon RX 580 2048SP (насыщенность, накопление истории, порог Bloom, пять режимов неба, прозрачность).
- tools/runtime-smoke.init.gradle добавляет тестовый entrypoint только для отдельного запуска. В релизный JAR он не включается. Тест открывает локальный мир, включает визуальные модули, открывает ClickGUI, меняет размер окна, отключает модули и сохраняет скриншоты.

Факт выполнения AutoResell на реальном сервере не проверялся. Формат цен и кнопок сервера должен соответствовать описанному выше. Автоматического подключения к серверу или торговли во время проверок не было.

## Исправление неработающих эффектов (13.09.2026)

Обнаружена ошибка в WorldEffects.copy: прямой GL30.glBindFramebuffer рассинхронизировал кэш GlStateManager. После этого Framebuffer.beginWrite мог пропустить переключение, и эффект не попадал в отображаемый framebuffer. Привязки READ/DRAW и blit переведены на GlStateManager. Переключение scissor также согласовано с кэшем Minecraft. Сила Motion Blur нормализована относительно 60 FPS.

Предыдущий запуск без GL-ошибок и тест отдельного GLSL не обнаруживали эту проблему. Теперь tools/runtime-smoke/SocketSmokeTest.java последовательно проверяет эффекты по одному в игровом мире. EffectComparisonCheck.java проверяет полученные изображения: chroma Saturation=0 составляет 0; средняя яркость Bloom увеличивается на 74/255; разница неба 93/255; видимая разница кадра с накоплением Motion Blur — 39/255. Это результаты отдельного тестового мира, без подключения к серверу.

Повторная проверка:
1. Запуск `gradlew runClient -I tools/runtime-smoke.init.gradle -x downloadAssets --args="--quickPlaySingleplayer Socket-QA --width 960 --height 540"` при наличии тестового мира и ресурсов.
2. `java tools/EffectComparisonCheck.java run/screenshots`.
3. Перед установкой — обычный `gradlew clean build`, без тестового init script. В релизе не должно быть runtime.SocketSmokeTest.
