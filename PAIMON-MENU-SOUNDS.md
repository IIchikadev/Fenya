# Звуки меню Паймон

Источник: https://github.com/SamToki/Genshin-Impact-Archive/blob/main/Genshin%20Impact%20Short%20Sound%20Collection.zip
Сборник SamToki, исходные эффекты Genshin Impact (HoYoverse).

PaimonMenuOpen.wav → assets/socket/sounds/menu_open.wav
PaimonMenuCloseWithPaimonDisappear.wav → assets/socket/sounds/menu_close.wav

Файлы PCM WAV перенесены без изменения. Настройки: Разное → Sounds → Звуки меню Паймон / Громкость меню. Настройка звуков меню независима от звуков переключения модулей. Звук открытия запускается один раз при показе ClickGUI; изменение размера окна его не повторяет. Звук закрытия запускается при удалении экрана, включая Escape, горячую клавишу и переход в другой экран.
